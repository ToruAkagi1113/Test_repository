# 九九練習アプリ

ブラウザだけで動く JavaScript 実装の九九練習用シングルページアプリです。

## 主な機能
- ランダムな 1〜9 の掛け算問題を出題
- 解答の正誤判定とフィードバック表示（成功時は次の問題へ自動遷移）
- 正解数・挑戦数・正答率の表示
- 現在の連続正解数とベスト連続数のバッジ表示
- 成績リセットボタンで正解数や連続数をいつでも初期化

## npm の確認
この環境では npm がインストールされており、`npm --version` は `11.4.2` を返しました。環境が変わった場合も、以下のコマンドで npm の有無とバージョンを確認できます。

```bash
npm --version
```

## 主なスクリプト
- `npm start`: 簡易サーバーでアプリを http://localhost:8000 から提供

## ローカル起動手順
ビルド不要の純粋な JavaScript 版なので、そのまま動作確認できます。

```bash
npm start                 # デフォルトで 8000 番ポートを使用
# または PORT でポート指定
PORT=4173 npm start
```
